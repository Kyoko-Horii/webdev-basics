HTML

The HTML Skeleton

Every website starts with the same basic structure. It's like a house — you need the frame before you can paint the walls. This is called the HTML skeleton.

The Full Skeleton

Copy this into a file called index.html:

<!-- This tells the browser: "I'm an HTML5 document" -->
<!DOCTYPE html>
<html lang="en">

  <!-- HEAD: invisible info about the page -->
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Page</title>
  </head>

  <!-- BODY: everything the user SEES -->
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first website.</p>
  </body>

</html>

What Each Part Means

Tag What it does
<!DOCTYPE html> Tells the browser "this is HTML5". Always put it on line 1.
<html lang="en"> The container for the whole page. lang="en" means "English language".
<head> Invisible settings: title, charset, viewport, links to CSS, etc.
<meta charset="UTF-8"> Lets you use special characters like ñ, é, and emojis 😀.
<meta viewport> Makes the site fit mobile screens properly. Essential for responsive design!
<title> The text shown in the browser tab.
<body> Everything the user actually sees on the page.
💡 Tip: Think of <head> as the "settings" of the page and <body> as the "content" of the page.

Text & Headings

Use headings (h1–h6) to organize content. Use paragraphs for normal text. Never use headings just to make text big — use CSS for that.

Golden Rules

  • Only ONE <h1> per page (usually the main title).
  • Go in order: h1 → h2 → h3. Don't skip.
  • Use <p> for paragraphs, not <br><br>.
  • Use <strong> for importance, <b> only for visual bold.
💡 Tip: Headings help screen readers and Google understand your page structure.

TagWhat it does

You can change how an ordered list numbers its items using the type attribute:

Links & Images

Links connect pages. Images show pictures. Both use the attribute system: name="value".

Links — Code Structure

<!-- LINK: href = where to go -->
<a href="https://google.com">Visit Google</a>

<!-- Open in new tab -->
<a href="https://google.com" target="_blank">Open new tab</a>

<!-- Link to another page on your site -->
<a href="about.html">About Us</a>

<!-- Link to a section on the same page (id) -->
<a href="#contact">Go to Contact</a>
AttributeWhat it does
hrefThe link destination (URL or file).
target="_blank"Opens link in a new tab.

Inserting Images (<img>)

The <img> tag shows a picture. It has no closing tag — it's a "self-closing" tag. The most important attributes are src and alt.

<!-- Basic image -->
<img src="cat.jpg" alt="A cute cat">

<!-- Image from the internet (URL) -->
<img src="https://picsum.photos/200/120" alt="Random photo">

<!-- Image with width and height -->
<img src="cat.jpg" alt="A cute cat"
     width="200" height="150">

<!-- Image inside a link (clickable image) -->
<a href="https://google.com">
  <img src="logo.png" alt="Google logo">
</a>
AttributeWhat it does
srcThe image file path or URL (required).
altText shown if image fails — also read by screen readers (required for accessibility).
widthImage width in pixels (or %).
heightImage height in pixels (or %).
titleTooltip shown when hovering over the image.
loading="lazy"Loads the image only when it's about to be seen (faster page).
💡 Tip: Always use alt! It helps blind users (screen readers) and shows text if the image fails to load. Google also uses it for image search.

Class, ID & Sections

Classes and IDs are labels you give to HTML elements so CSS and JavaScript can find them. They don't change how the element looks on their own — you need CSS for that.

Specifying a Class

Use class="name" on any element. Multiple elements can share the same class.

<!-- Many elements can use the same class -->
<p class="highlight">First paragraph</p>
<p class="highlight">Second paragraph</p>
<div class="highlight">A box</div>

<!-- An element can have MULTIPLE classes (space-separated) -->
<p class="highlight big-text centered">Styled in 3 ways</p>

In CSS, a class is written with a dot:

.highlight { background: yellow; }
.big-text { font-size: 24px; }

Specifying an ID

Use id="name". An ID must be unique — only ONE element per page can have a given ID.

<!-- Only ONE element can have id="main-title" -->
<h1 id="main-title">Welcome</h1>

<!-- IDs are also used for in-page links -->
<a href="#main-title">Jump to title</a>

In CSS, an ID is written with a hash (#):

#main-title { color: navy; }

Difference Between Class and ID

Class (.name)

✅ Can be used on many elements

✅ One element can have multiple classes

✅ Reusable — great for styling groups

CSS: .button { … }

Use for: styling, reusable styles

ID (#name)

✅ Must be unique (only one per page)

✅ Higher priority in CSS than class

✅ Used for page anchors (#section)

CSS: #header { … }

Use for: unique elements, JS targets, page anchors

Sections

The <section> tag groups related content. Each section usually has its own heading (h2, h3, etc.). It's a semantic way to divide a page.

<section id="about">
  <h2>About Us</h2>
  <p>We build websites…</p>
</section>

<section id="services">
  <h2>Our Services</h2>
  <p>Web design, development…</p>
</section>

Common practice: give each section an id so you can link to it (e.g. <a href="#about">).

Full Example

<style>
  .card { border: 1px solid #ccc; padding: 10px; margin: 10px; }
  .highlight { background: yellow; }
  #main-title { color: navy; text-align: center; }
</style>

<h1 id="main-title">My Page</h1>

<section id="about">
  <h2>About</h2>
  <div class="card">
    <p class="highlight">Important note!</p>
    <p>Normal text.</p>
  </div>
</section>
💡 Tip: Use classes for styles you want to reuse, and IDs for unique, one-of-a-kind elements (like a main header or a section you link to).

CSS Basics

CSS = Cascading Style Sheets. It controls how HTML looks: colors, fonts, spacing, layout.

3 Ways to Add CSS

<!-- 1. INLINE (inside the tag — avoid if possible) -->
<p style="color: red;">Red text</p>

<!-- 2. INTERNAL (inside <head>) -->
<style>
  p { color: blue; }
</style>

<!-- 3. EXTERNAL (best!) -->
<link rel="stylesheet" href="style.css">

There's a full lesson comparing all three later — see "8. External, Internal & Inline" in the CSS menu.

CSS Syntax

Every CSS rule looks the same:

selector {
  property: value;
  property: value;
}

/* Example: */
p {
  color: blue;
  font-size: 18px;
}
PartMeaning
selectorWhich element(s) to style (e.g. p = all paragraphs).
propertyWhat to change (e.g. color, font-size).
valueThe setting (e.g. red, 18px).
;Ends each declaration (don't forget!).

The Box Model

Every HTML element is a box with 4 layers: content → padding → border → margin. Understanding this is the #1 CSS skill.

/* BOX MODEL in code */
.box {
  width: 200px;              /* content width */
  padding: 20px;              /* inner space */
  border: 3px solid black;     /* the border */
  margin: 30px;               /* outer space */
}
PropertyWhat it does
width / heightThe content box size.
paddingSpace inside the border (around the content).
borderThe line around the padding.
marginSpace outside the border (between elements).
box-sizing: border-boxMakes width include padding + border. Recommended always!

Padding vs Margin — Detailed

Padding (inside)

Space inside the element, between the content and the border.

Adding padding makes the element bigger.

Background color covers the padding area.

Example: padding: 20px;

Margin (outside)

Space outside the element, between it and other elements.

Adding margin does not make the element bigger — it pushes neighbors away.

Background color does not cover margin.

Example: margin: 20px;

All 4 Sides: shorthand

/* One value = all 4 sides */
padding: 10px;

/* Two values = top/bottom  left/right */
padding: 10px 20px;

/* Three values = top  left/right  bottom */
padding: 10px 20px 30px;

/* Four values = top  right  bottom  left (clockwise) */
padding: 10px 20px 30px 40px;

/* Individual sides */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;

/* Same works for margin */
margin: 0 auto;   /* centers a block horizontally */
ShorthandTopRightBottomLeft
padding: 10px;10101010
padding: 10px 20px;10201020
padding: 10px 20px 30px;10203020
padding: 10px 20px 30px 40px;10203040

Responsive Design

Responsive design means your site looks good on phones, tablets, and desktops. The main tool is media queries.

/* Default: mobile-first styles */
.container { width: 100%; }

/* When screen is 768px or wider (tablet/desktop) */
@media (min-width: 768px) {
  .container { width: 750px; }
}

/* When screen is 1024px or wider (desktop) */
@media (min-width: 1024px) {
  .container { width: 1000px; }
}
PartWhat it does
@mediaStarts a media query block.
min-widthApplies when screen is at least that wide.
max-widthApplies when screen is at most that wide.
% / rem / frFlexible units — better than fixed px for layouts.

External, Internal & Inline CSS

There are 3 places you can write CSS. Each has a different use. Here's the full breakdown.

1. Inline CSS

Written directly inside an HTML tag using the style attribute. It only affects that one element.

<p style="color: red; font-size: 18px;">Red text</p>

<h1 style="text-align: center; color: navy;">Centered title</h1>
ProsCons
Quick for one-off changesHard to reuse across many elements
Overrides other CSS (highest priority)Messy HTML — mixes content and style
Good for testing quicklyCannot use pseudo-classes like :hover

2. Internal CSS

Written inside a <style> tag, usually in the <head>. It affects the whole page.

<head>
  <style>
    body { background: #f0f0f0; }
    h1   { color: navy; text-align: center; }
    .note { background: yellow; padding: 8px; }
  </style>
</head>
ProsCons
All styles in one place (the page)Cannot be shared with other pages
No extra file neededIf you have 10 pages, you repeat it 10 times
Good for single-page sitesPage gets heavy with lots of CSS

3. External CSS

Written in a separate .css file and linked with <link>. It can style many pages at once — this is the best practice.

<!-- In your HTML <head> -->
<link rel="stylesheet" href="style.css">

/* Inside style.css */
body {
  font-family: Arial, sans-serif;
  background: #f8f8f8;
}

h1 { color: navy; }

.card {
  border: 1px solid #ccc;
  padding: 16px;
}
ProsCons
Reusable across many pagesNeeds an extra HTTP request (very minor)
Cleaner HTML (no style mixing)Requires file management
Browser caches it (faster on repeat visits)—
Easy to maintain—

Which One Wins? Priority Order

If you use all three, the browser applies them in this priority (highest first):

  1. Inline (style="...") — wins over everything
  2. Internal (<style>) — wins over external
  3. External (.css file) — base styles

Tip: Use !important to force a rule to win, but use it sparingly.

When to use Inline

Quick test, one-off tweaks, HTML emails (which don't support external CSS).

When to use Internal

Single-page sites, or a page that needs unique styles not used anywhere else.

When to use External

For real projects with multiple pages. This is what professional developers use 95% of the time.

🧪 Try it yourself!
💡 Tip: In real projects, put ALL your CSS in an external .css file. Keep HTML clean. Only use inline for tiny one-off fixes.
BACKEND

Getting Started with XAMPP

XAMPP is a free program that lets you run PHP and MySQL on your own computer — no hosting needed. It's the easiest way to learn backend.

Setup Steps

  1. Download XAMPP from apachefriends.org.
  2. Install it (default options are fine).
  3. Open the XAMPP Control Panel.
  4. Click Start next to Apache (the web server).
  5. Click Start next to MySQL (the database).
  6. Open your browser and go to http://localhost — you should see the XAMPP dashboard.
💡 Tip: Your website files go inside C:\xampp\htdocs\. Create a folder there, e.g. htdocs\mysite\, and visit http://localhost/mysite/.

phpMyAdmin

Go to http://localhost/phpmyadmin — this is where you create and manage MySQL databases visually.

PHP Basics

PHP runs on the server. It generates HTML that gets sent to the browser. Save files as .php.

PHP Syntax

<?php
  // 1. Variables start with $
  $name = "Maria";
  $age = 25;

  // 2. Print to the page
  echo "Hello, $name!";

  // 3. Conditionals
  if ($age >= 18) {
    echo "Adult";
  } else {
    echo "Minor";
  }

  // 4. Loops
  for ($i = 1; $i <= 5; $i++) {
    echo $i . " ";
  }

  // 5. Arrays
  $fruits = ["apple", "banana", "mango"];
  foreach ($fruits as $fruit) {
    echo $fruit;
  }
?>
PartWhat it does
<?php … ?>PHP code block. Everything between runs on the server.
$variableA variable — always starts with $.
echoPrints text to the page.
. (dot)Joins two strings together.
//A comment — ignored by PHP.
📌 Note: PHP cannot run inside this in-browser editor because it needs a server. To test it, save the file as test.php inside C:\xampp\htdocs\test\ and open http://localhost/test/test.php.

Handling Forms in PHP

This is the core of backend: user types in a form → PHP receives it → PHP responds.

1. The HTML form

<form method="POST" action="process.php">
  <label>Name:</label>
  <input type="text" name="name">
  <button>Submit</button>
</form>

2. The PHP that receives it (process.php)

<?php
  if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $name = $_POST["name"];
    echo "Hello, $name!";
  }
?>
PartWhat it does
method="POST"Sends data in the request body (hidden from URL).
method="GET"Sends data in the URL (visible, for searches).
$_POST["name"]Gets the value of the input called "name".
$_GET["q"]Gets the value sent by GET.
$_SERVER["REQUEST_METHOD"]Tells you if the form was submitted.

MySQL Database

A database stores data permanently. MySQL is the most common with PHP.

Steps to connect

  1. Open http://localhost/phpmyadmin.
  2. Click New and create a database, e.g. myschool.
  3. Create a table, e.g. students, with columns: id (INT, auto-increment), name (VARCHAR 100), age (INT).
  4. In your PHP file, connect using the code below.

Connection Code

<?php
  $conn = new mysqli(
    "localhost",   // server
    "root",        // username (XAMPP default)
    "",            // password (XAMPP default: empty)
    "myschool"     // database name
  );

  if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
  }
  echo "Connected successfully!";
?>
PartWhat it does
new mysqli(...)Creates a connection to MySQL.
"localhost"The server (local XAMPP).
"root"The default XAMPP username.
connect_errorHolds an error message if the connection failed.

CRUD Example

CRUD = Create, Read, Update, Delete. These are the 4 operations on any database. This is the foundation of every web app.

Create — Insert a row

<?php
  $sql = "INSERT INTO students (name, age) VALUES ('Maria', 25)";
  if ($conn->query($sql) === TRUE) {
    echo "New record created!";
  }
?>

Read — Get rows

<?php
  $sql = "SELECT id, name, age FROM students";
  $result = $conn->query($sql);

  while ($row = $result->fetch_assoc()) {
    echo $row["id"] . " - " . $row["name"] . "<br>";
  }
?>

Update — Change a row

<?php
  $sql = "UPDATE students SET age = 26 WHERE id = 1";
  $conn->query($sql);
?>

Delete — Remove a row

<?php
  $sql = "DELETE FROM students WHERE id = 1";
  $conn->query($sql);
?>
💡 Tip: Always use prepared statements when inserting user input (search "PHP prepared statements"). It prevents SQL injection — the #1 security issue for beginners.

What to Learn Next

  • JavaScript — makes pages interactive.
  • Prepared statements — for safe database queries.
  • PDO — a more modern way to use MySQL in PHP.
  • Sessions — for login systems.
  • A framework — Laravel, React, or Next.js for real projects.
